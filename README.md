# CloudSure

AI-Native Cloud Insurance Platform

## Vision

CloudSure is a cloud-native insurance platform supporting:

- Auto Insurance
- Home Insurance
- Life Insurance

The platform leverages:

- Spring Boot
- Kafka
- Kubernetes
- Terraform
- AWS
- PostgreSQL
- Redis
- Spring AI
- pgvector

to modernize insurance operations and deliver measurable business value.

## Key Capabilities

- Policy Management
- Claims Management
- Fraud Detection
- AI Claims Assistant
- Insurance Copilot
- Executive ROI Dashboard
- Event Driven Architecture
- Real-Time Analytics
