# Scope Management Plan

**Project:** CloudSure - AI Native Insurance Platform

---

# Purpose

Defines how project scope will be defined, managed, validated, and controlled.

---

# Scope Management Process

The project follows:

```text
Scope Definition
    ↓
Scope Validation
    ↓
Scope Control
```

---

# Scope Baseline

The approved scope baseline consists of:

- Project Charter
- Business Case
- Product Backlog
- MVP Definition

---

# In Scope

## Business Capabilities

- Customer Management
- Policy Management
- Claims Management
- AI Assistance
- Executive Dashboards

---

## Technical Capabilities

- Spring Boot Microservices
- Kafka
- PostgreSQL
- Redis
- Kubernetes
- AWS

---

# Out Of Scope

Current Release

- Mobile Applications
- Multi-cloud Deployments
- Advanced ML Training Pipelines
- Real-Time Telematics

---

# Scope Validation

Scope shall be validated against:

- Approved Requirements
- MVP Definition
- Release Plan

---

# Scope Change Process

Any change proposal must include:

- Description
- Business Justification
- Impact Assessment
- Risk Analysis

Approval required from:

- Product Owner
- Project Manager
- Architecture Lead

---

# Scope Control

Scope changes shall be tracked through:

- Product Backlog
- Change Requests
- Architecture Review Board
