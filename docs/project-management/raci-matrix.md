# RACI Matrix

**Project:** CloudSure - AI Native Insurance Platform

---

# Purpose

Defines accountability and responsibilities across project activities.

---

# Roles

- Executive Sponsor (ES)
- Product Owner (PO)
- Project Manager (PM)
- Architecture Lead (AL)
- Engineering Team (ENG)
- QA Engineer (QA)

---

# Legend

R = Responsible

A = Accountable

C = Consulted

I = Informed

---

# RACI Matrix

| Activity | ES | PO | PM | AL | ENG | QA |
|------------|----|----|----|----|----|----|
| Requirements Gathering | I | A | C | C | I | I |
| Product Prioritization | I | A | C | I | I | I |
| Architecture Design | I | C | I | A | R | I |
| Technology Selection | I | C | I | A | R | I |
| Development | I | I | I | C | A | C |
| Testing | I | I | I | C | R | A |
| Security Review | I | I | C | A | R | C |
| CI/CD Setup | I | I | I | C | A | C |
| Release Approval | A | C | R | C | I | I |
| Risk Management | I | C | A | C | I | I |
| Stakeholder Reporting | A | C | R | I | I | I |

---

# Usage

The matrix shall be reviewed:

- At phase boundaries
- During major releases
- When team structure changes
