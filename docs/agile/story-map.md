# User Story Map

**Project:** CloudSure - AI Native Insurance Platform

---

# Customer Journey

## Manage Account

### User Stories

As a customer, I want to register an account so that I can access insurance services.

As a customer, I want to login securely so that I can manage my policies.

---

## Manage Policies

### User Stories

As a customer, I want to view my policies so that I can understand my coverage.

As a customer, I want to renew a policy so that I maintain coverage.

---

## Submit Claim

### User Stories

As a customer, I want to submit a claim so that I can request compensation.

As a customer, I want to upload supporting documents so that my claim can be reviewed.

As a customer, I want to track claim status so that I know the progress of my claim.

---

# Claims Adjuster Journey

## Review Claims

### User Stories

As a claims adjuster, I want to view submitted claims so that I can evaluate them.

As a claims adjuster, I want AI-generated claim summaries so that I can reduce review time.

As a claims adjuster, I want fraud indicators so that I can identify suspicious claims.

---

## Decision Claims

### User Stories

As a claims adjuster, I want to approve claims so that valid claims can be settled.

As a claims adjuster, I want to reject invalid claims so that company policy is enforced.

---

# Executive Journey

## Review Operations

### User Stories

As an executive, I want to see claims processing metrics so that I understand operational performance.

As an executive, I want to track AI adoption so that I can measure transformation progress.

As an executive, I want to view cost savings so that I can evaluate ROI.

---

# Operations Journey

## Monitor Performance

### User Stories

As an operations manager, I want to view workload distribution so that resources can be allocated effectively.

As an operations manager, I want SLA dashboards so that service performance can be monitored.

---

# AI Journey

## Insurance Copilot

### User Stories

As a customer, I want an AI assistant that answers coverage questions so that I can understand my policy.

As a customer, I want claim guidance so that I know what information is needed.

---

## Claims Investigation Agent

### User Stories

As an adjuster, I want AI-generated claim recommendations so that I can review claims faster.

As an adjuster, I want supporting evidence referenced so that recommendations remain explainable.
