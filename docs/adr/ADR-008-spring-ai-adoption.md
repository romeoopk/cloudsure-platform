# ADR-008: Adopt Spring AI As AI Integration Framework

## Status

Accepted

## Date

July 2026

---

# Context

CloudSure requires AI capabilities including:

- Chat
- Retrieval Augmented Generation
- Tool Calling
- Agent Workflows

The solution should align with the Spring ecosystem.

---

# Decision

Spring AI shall be the standard AI integration framework.

---

# Capabilities

Spring AI will provide:

- Chat Models
- Embeddings
- Vector Stores
- Tool Calling
- Agent Enablement

---

# Rationale

Benefits:

- Spring ecosystem alignment
- Simplified AI integration
- Provider abstraction
- Strong developer experience

---

# Usage

Examples:

- Insurance Copilot
- Claims Investigation Agent
- Fraud Assistant
- Executive Assistant

---

# Consequences

Positive:

- Reduced integration complexity
- Consistent AI architecture

Negative:

- Dependency on Spring AI maturity

---
